📊 Relatório de Insights Estratégicos de Marketing (B2B)

Este projeto de Business Intelligence apresenta um dashboard de Análise de Oportunidades de Marketing, desenvolvido para qualificar a base de clientes potenciais (B2B). O objetivo é cruzar dados de orçamento, estrutura interna e engajamento para identificar quais empresas têm maior propensão de compra e devem ser priorizadas pela equipe comercial.

O painel oferece uma visão competitiva (Benchmarking) e uma ferramenta de priorização automática baseada em relacionamento prévio.
